# nvim-web-devicons：文件类型图标

仓库：`nvim-tree/nvim-web-devicons`。作为 nvim-tree 依赖加载，根据扩展名、文件名和颜色主题
提供图标。本项目没有独立 setup 或快捷键。

它依赖终端 Nerd Font 字形。方块、问号或列宽错位时，先在终端 profile 选择 Nerd Font，
再检查 locale/UTF-8；换插件配置通常不能修复字体缺字。默认未知文件图标在 nvim-tree 配置中
另设为 ``。

上游：[nvim-web-devicons](https://github.com/nvim-tree/nvim-web-devicons)。
