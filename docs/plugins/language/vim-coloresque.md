# vim-coloresque：颜色字面量预览

仓库：`gko/vim-coloresque`，在 PHP、HTML、JavaScript、CSS、Less 文件加载。它给 `#rrggbb`
等颜色文本设置接近实际颜色的背景/前景，便于检查样式。

本项目无自定义配置。若颜色不显示，确认 filetype 属于声明列表、终端 true color 已开启，
并查看是否被 TokyoNight/Tree-sitter 的后续 highlight 覆盖。它不提供颜色选择器，也不会
修改色值。

上游：[vim-coloresque](https://github.com/gko/vim-coloresque)。
