# cmp-path：文件与目录路径补全

**仓库：** `hrsh7th/cmp-path`。是 nvim-cmp 的依赖，源配置位于 [nvim-cmp.lua](../../../lua/config/nvim-cmp.lua)，名称为 `path`。

## 当前作用与用法

在插入模式输入路径前缀时，将磁盘中的目录和文件提供给补全菜单。它只插入路径文本，不打开文件、不生成 Markdown 链接结构，也不会验证文件内容。项目未配置路径映射或自定义路径源选项。

例如编辑已保存的 Markdown 文件时输入 `./`，查看同目录候选；选择目录继续输入子路径。按 Ctrl-Space 请求候选、Tab 选中、回车确认。搭配 Markdown 的 `,a` 或 `,p` 插入链接模板后，可在目标位置补全路径。

## 初始条件与排错

无需安装外部 CLI。确保目标目录存在且 Neovim 有读取权限，用 `:CmpStatus` 看源状态。未保存文件没有稳定的文件目录，先保存再试。项目启用了 `autochdir`，切换文件时工作目录会改变；遇到候选目录与预期不同，用 `:pwd` 和 `:echo expand("%:p:h")` 对照。[上游选项及路径规则](https://github.com/hrsh7th/cmp-path)

两个分支均使用默认选项。Windows 路径建议优先尝试 `./` 和斜杠形式，盘符、空格及反斜杠需要在 Windows 11 实机检查；本文未完成该平台测试。
