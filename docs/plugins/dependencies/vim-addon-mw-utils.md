# vim-addon-mw-utils：Vimscript 工具库

仓库：`MarcWeber/vim-addon-mw-utils`。两个分支把它作为底层条目直接声明；它提供缓存、对象、
列表等 Vimscript 辅助函数，常由旧式插件间接使用。

本项目没有直接调用、命令或快捷键。正常使用无需配置；删除前应检查 PIV 等传统插件的运行
依赖。插件管理器能下载它不代表用户需要主动打开它。版本由锁文件固定。

上游：[vim-addon-mw-utils](https://github.com/MarcWeber/vim-addon-mw-utils)。
